# HotelMaps_System (ComfortVue Philippines)

ComfortVue is an interactive hourly motel, condo staycation, and function facility discovery engine built with **Vue 3**, **Bootstrap 5**, and **Leaflet Maps**.

## Features Included:
- **Interactive Multi-layer Map**:
  - OpenStreetMap Standard
  - Esri World Imagery (High-Resolution Satellite)
  - CartoDB Dark Matter
- **Real-Time GPS Route & Direction Visualizer**:
  - Distance estimation in kilometers
  - Live travel time calculations
  - Route polyline display
- **Custom Price Tag Markers**:
  - Color-coded price badges matching motel, condo, and study facilities.
- **Embedded Database & Admin Management**:
  - Add, edit, and delete locations with automatic map updates.
  - Active booking storage using local persistent storage.
- **ZIP Bundler**:
  - Browser-native zero-dependency archive builder.

## How to Run:
Double click `index.html` in any web browser (Chrome, Edge, Firefox, Safari). No Node.js build process is required!
